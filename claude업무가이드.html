GitHub 연동 & 403 에러 해결

1
Git 전역 설정git config --global user.name "이름" git config --global user.email "your@company.com"
2
PAT 발급: GitHub → Settings → Developer settings → Tokens (classic) → repo + workflow 체크
3
403 에러 시 — 다른 계정 캐시 충돌 해결git remote set-url origin https://[username]:[토큰]@github.com/[username]/[repo].git git push -u origin main
4
workflow 권한 없을 시 — PAT에 workflow 체크 후 재발급

💡 GitHub vs Firebase 비교
GitHub Pages — 소스 코드와 함께 관리, 팀 내부 공유, git push 자동 배포, 무료
Firebase Hosting — 외부 공개, 커스텀 도메인, 글로벌 CDN, 고성능 캐싱, Google 계정 통합 관리
